# MOAMOA-87 — 종료와 결과 (누락된 4단계 보완)

이 문서는 이전 단계 문서의 '자동 종료/연장/결과 미구현' 설명을 대체한다.

## 기존 구현과 추가 범위

기존 useAuctionClock은 표시 전용이며, endTimeAfterAcceptedBid는 미연결 순수 함수였다.
결과 타입/배열은 있었지만 실제 종료 액션/판정/모달은 없었다.
입찰 및 채팅 입력 처리는 재구현하지 않고 제출 경계와 화면 연결만 추가했다.

- finishExpiredAuctions: IN_PROGRESS이며 종료 시각에 도달한 경매를 한 번에 ENDED로 바꾸고 결과를 저장한다.
- 종료 시 canEnter=false, version 증가. 결과는 경매당 한 번만 추가하며 채팅/입찰 내역은 보존한다.
- 목록과 상세의 useAuctionLifecycle은 마운트, 250ms interval, focus, visibilitychange에서 절대 시각을 재검증한다.
- 다른 페이지에서는 폴링하지 않으며 경매 화면 재진입 시 누락된 종료를 반영한다. 새로고침은 기존 초기화 정책을 유지한다.
- 입찰/채팅 제출 직전에도 종료를 판정하므로 백그라운드 timer 지연으로 마감 후 제출할 수 없다.
- Public 유효 입찰: 0초 초과/10초 이하이면 submittedAt+10초, 10초 초과이면 기존 endTime 유지.
  입찰 기록/최고가/입찰자/종료 시각을 같은 set에서 갱신한다. 정확히 0초는 종료 후 거절한다.
- Private은 연장 없이 각 사용자의 최신 수락 기록으로 판정한다. 낮춘 마지막 금액도 유효하다.
- 입찰 없음은 UNSOLD, 단독 최고가는 SOLD, 최고 금액 동률은 PENDING_TIE로 보류한다.
  동률에서 임의 낙찰자나 유찰을 만들지 않는다. winnerId/winningAmount는 null이다.
- 결과 endedAt은 관찰 시각이 아닌 실제 endTime이다. 정산/아이템 이전은 수행하지 않는다.
- 종료 전 Private 결과는 숨기며 종료 후 낙찰 결과만 공개한다. 다른 사용자의 입찰 이력은 계속 숨긴다.

## 결과 UI

두 SVG를 원본 수정 없이 임시 PNG로 렌더링해 확인했다.
1920×1080 기준 x730/y309, 460×463 흰 패널, #eee 테두리, 모서리12,
아이템 패널 x840/y369 240×160 cream, 광장 이동 버튼 x810/y677 부근을 반영했다.
실행 화면은 SVG 전체를 사용하지 않고 기존 아이템 에셋과 React 텍스트/링크로 구성한다.
공통 Modal을 변경하지 않고 경매 전용 native dialog를 사용한다.
showModal로 배경 조작을 차단하고 Escape/바깥 클릭으로 닫히지 않으며 닫기 버튼은 없다.
광장으로 이동은 / 링크다. 입찰 모달은 ENDED/결과 발생 시 unmount하고 성공 알림은 숨긴다.
본인 낙찰은 현재 닉네임, 이름 정보가 없는 다른 낙찰자는 '참가자'로 표시한다. 원시 회원 ID는 표시하지 않는다.
PENDING_TIE 안내는 디자인에 없으므로 동일 패널에 정책 확인 필요 문구를 표시한다.
