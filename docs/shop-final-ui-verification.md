모달 이미지·글자·버튼·테두리를 함께 축소한다. 모든 화면에서 뷰포트 안에 표시됐다. 가격 1,200 / 보유 화폐 1,000 / 부족한 금액 200, 빨간 부족액(rgb(230,69,74)), 정확한 경고 문구, 구매 비활성화를 확인했다. 일반 구매 모달은 세 데스크톱에서 기존 높이 652px를 유지했다.

## 알림·거래 검증

세 데스크톱 및 추가 모바일에서 각각 5상품 × 구매/판매, 총 40건 검증:

- 모든 메시지 한 줄, white-space: nowrap. 문구 높이와 코인 높이 일치.
- /assets/ui/coin.svg 로딩 성공. 메시지 → 코인 → 금액 순서.
- 구매 − / 판매 +, 기존 상품 가격 표시.
- 원래 메시지 Jua 24px, 금액 20px, 자간 −0.25px 유지.
- 원래 메시지–코인 12px, 코인–금액 0px 유지(각 화면 배율 적용). 상품에 따른 불필요한 공백 없음.
- 전체 콘텐츠 중앙 오차 0.1px 미만. 화면 바깥 넘침 없음.
- 실제 시간 4초 후 표시, 5.15초 후 제거를 네 뷰포트에서 확인.
- 별도 브라우저 시계 테스트: 4999ms 표시, 5000ms 제거. 판매 3초 뒤 구매하면 이전 판매 종료 시점에도 구매 알림이 유지되고 새 구매로부터 5000ms에 제거.
- 구매 후 500, 판매 후 1,000, 재구매 후 500 잔액과 보유 상태 정상.

## 원본과 남은 차이

- 모달은 기존 dialog의 뷰포트 중앙 정렬을 유지한다. 따라서 1920×1080에서 Y=170.5이며 제공 PNG의 Y=232와 다르다. 내부 800×739 비율은 유지하며 작은 화면에서는 전체 축소한다.
- 기존 버튼 스타일을 유지하므로 비활성 구매 버튼 높이는 61px이고 원본 SVG의 약 55px와 다르다. 금액 패널의 일반 숫자는 기존 검정색이며 원본은 브라운이다.
- 하트 선글라스는 요청대로 캡슐 너비를 확장한다. 리본 판매 금액은 기존 데이터 +400을 유지하며 원본의 +200과 다르다.
- 기존 pixelated 이미지와 브라우저 Jua 렌더링은 SVG에 포함된 이미지/문자 윤곽과 안티앨리어싱 차이가 있다. 기존 픽셀아트 처리는 변경하지 않았다.
